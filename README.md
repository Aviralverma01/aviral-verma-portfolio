# Aviral Verma — Developer Portfolio

Premium dark portfolio built with Next.js, React, TypeScript, Tailwind CSS, Motion and Lenis.

## Source of truth
All personal content currently comes from the supplied resume. No GitHub repositories, live demos, AI product names, or unverified technologies were invented.

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing
- Add verified GitHub repository URLs and live demos to `lib/data.ts`.
- Add only AI tools you have genuinely used if you want them named in the AI-assisted development section.
- Replace/add favicon and OG image in `app/` or `public/` when branding assets are available.
